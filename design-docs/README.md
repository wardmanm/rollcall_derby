# Design docs (working papers)

This folder holds dated working papers produced while designing and building features:

- `specs/YYYY-MM-DD-<topic>-design.md`: design specs written during brainstorming, before implementation.
- `plans/YYYY-MM-DD-<topic>.md`: step-by-step implementation plans.

**These are not the wiki.** Each one is a snapshot of thinking at a point in time and is not kept up to date after its work is done. The docs lint doesn't check this folder.

The durable outcome of a spec or plan goes into the [wiki](../docs/README.md) in the same change that implements it:
- behavior goes on a feature page;
- structure goes on an architecture page;
- decisions go in an ADR.

If a working paper and the wiki disagree, the wiki is right.
